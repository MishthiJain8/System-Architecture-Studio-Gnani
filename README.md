# Architecture Studio

An interactive system-design canvas with a visual event-flow simulator.

## Quick start

```bash
pnpm install
pnpm dev
```

- Web canvas: http://localhost:3000
- NestJS GraphQL endpoint: http://localhost:4000/graphql

## Workspace

- `apps/web` — Next.js, Tailwind, and React Flow canvas; deploy to Vercel.
- `apps/api` — NestJS API with GraphQL and Socket.IO gateway; deploy to Render.
- `packages/shared` — diagram contracts shared by both applications.
